# FrontCore Phases Documentation

Version: 1.0

## Objetivo

Esta pasta guarda documentação detalhada por fase quando `docs/PHASES.md` não for suficiente.

`docs/PHASES.md` continua a ser o índice principal das fases.

## Regra

Criar um ficheiro por fase apenas quando houver detalhe real para documentar.

Exemplos:

```text
docs/phases/phase-3-ui.md
docs/phases/phase-3-3-ui-foundation.md
```

## Conteúdo recomendado por fase

Cada ficheiro de fase deve conter:

- objetivo
- escopo permitido
- fora de escopo
- ficheiros envolvidos
- dependências
- critérios de conclusão
- comandos de validação
- estado final

## Estado atual

A Fase 3 está relacionada com UI base.

A Fase 3.3 deve focar a foundation técnica de `packages/ui`, sem alterar comportamento da aplicação.
